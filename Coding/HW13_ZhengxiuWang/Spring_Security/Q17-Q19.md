### 17. What is the role of `configure(HttpSecurity http)` and `configure(AuthenticationManagerBuilder auth)`?
- `configure(HttpSecurity http)`: Defines security rules for HTTP requests (like which URLs require authentication, login/logout settings, CSRF, etc).
- `configure(AuthenticationManagerBuilder auth)`: Sets up authentication logic (such as in-memory, JDBC, or custom user details service).

### 19. Explain best practices to securely store secrets in applications.
- Never hardcode secrets in source code.
- Use environment variables or secret management tools (e.g. Vault, AWS Secrets Manager).
- Encrypt sensitive files or use secure property sources (e.g. Spring Cloud Config with encryption).
- Limit access with proper file/system permissions.
