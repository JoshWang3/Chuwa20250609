Testing related:

1.Unit Testing

Unit testing is meant to test the correctness of smallest part of project, like a method in isolation. Test writing with JUnit associate to a method is a unit test.

2.Functional Testing

Functional testing check the correctness of a specific function or feature in the project. It focus on what the system's behavior rather than what method the system used to implement that. Test the login feature with correct/wrong credentials is functional testing

3.Integration Testing

Integration Testing is to verify the communication between different systems. Testing the database accessing in a backend service is integration testing

4.Regression Testing

Regression testing is re run previous tests after code change to ensure the existing function correct. Github testing repo after each commit is regression testing

5.Smoke Testing

Smoke testing is to verify If some basic functions of the project works after deploying. If it passed, the deploying is probably correct. Some server have check status or say hello api, is a part of smoke testing

6.Performance testing is to test the performance related data, like execution speed, response time. Test the response time of the api after deploying is performance testing

7.Stress testing is to test the stability of the application under a high workload. Testing QPS is a stress testing

8.A/B testing is to test two or more variant of system which is better. Showing different variant of system like color to different users and compare the statistics is AB testing

9.End to End testing is to test all part of system by simulate using the system like a real user . Make a script to operate the system like a user is end to end testing

10.User Acceptance Testing is performed by selected users to confirm the system could comply with the user's need. Find some users to use system in real, and ask them is user acceptance testing

Environment:

1.Development

In Development environment, the developers write new features, run unit tests and debug locally. Test is mainly performed by developers

2.QA

QA Environment is a special environment where QA could run functional and integration test over the whole system. Test is mainly performed by QA

3.Pre-prod/Staging Environment is a environment which is like mirror of production environment for final validation. Performance test and stress test could by done in this stage. Test is mainly performed by QA and Devops.

4.Production environment is the live environment serving the real users. If no issues found in the application in previous stages, the version could deploy to the production environment.
