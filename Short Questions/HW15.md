# HW15

## 1. Explain monolithic architecture, service oriented architecture and Micro service architecture.

- **Monolithic Architecture**: A single unified codebase where all components (UI, business logic, data access) are tightly coupled and deployed together.
- **Service-Oriented Architecture (SOA)**: Application is divided into services that communicate over an enterprise bus. Promotes reusability and integration but can be heavyweight.
- **Microservice Architecture**: Breaks down applications into small, independent services that communicate via lightweight protocols (e.g., HTTP/REST). Each service is independently deployable and scalable.

---

## 2. Document the microservice architeture and core components

### Core Components:
- **Service Discovery**: Registers and locates services (e.g., Eureka).
- **API Gateway**: Entry point for clients, routes requests to services (e.g., Spring Cloud Gateway).
- **Config Server**: Centralized external configuration management (e.g., Spring Cloud Config).
- **Service Communication**: HTTP/REST, gRPC, or messaging (e.g., RabbitMQ, Kafka).
- **Resilience**: Circuit breakers, retries, bulkheads (e.g., Resilience4j, Hystrix).
- **Distributed Tracing**: Monitors requests across services (e.g., Sleuth, Zipkin).
- **Security**: Authentication and authorization via tokens (e.g., OAuth2).

---

## 3. Explain Resilience patterns? Explain circuit breaker with Spring Cloud Hystrix code example.

### Common Resilience Patterns:
- **Circuit Breaker**: Prevents calls to failing services.
- **Retry**: Automatically retries failed requests.
- **Timeouts**: Aborts slow operations.
- **Bulkhead**: Isolates resources to prevent cascading failures.
- **Rate Limiter**: Controls request rate.

### Circuit Breaker Example (Spring Cloud Hystrix):
```java
@RestController
public class UserController {
    
    @Autowired
    private UserService userService;

    @GetMapping("/user/{id}")
    @HystrixCommand(fallbackMethod = "fallbackUser")
    public User getUser(@PathVariable String id) {
        return userService.getUserById(id);
    }

    public User fallbackUser(String id) {
        return new User("default", "fallback-user");
    }
}
```

## 4. Load Balancing Algorithms

- Round Robin: Distributes requests sequentially.
- Random: Selects a server randomly.
- Least Connections: Chooses server with fewest active connections.
- IP Hash: Hashes client IP to determine server.
- Weighted Round Robin: Weights servers by capacity.

## 5. API Gateway

A single entry point for all clients. Handles request routing, composition, authentication, rate limiting, and monitoring.

Examples: Spring Cloud Gateway, Zuul, Kong.

## 6. Explain service discovery and service registry

### Service Registry
A database of available services (e.g., Eureka).

### Service Discovery
Mechanism for finding services.
- Client-side: Client queries registry directly.
- Server-side: Gateway or load balancer queries registry.
