1.

Monolithic architecture is that an application build all functions together with a single, unified unit. They must deployed together to use. Error in any function will cause failure in whole application.

Service Oriented Architecture is to struct the application of a collection of services, each service provide a specific function. Services could communicate with each other with Enterprise Service Bus

Microservice architecture provide more fine grained partitions to the services, each microservice is totally independent, make the system more distributed.

2.

Core components in microservice architecture contains:

API gateway: Routing the api request to the correct microservice to handle

Load Balancer: Distribute the api request to multiple servers to enhance the performance and threshold.

Circuit breaker: Define fallback ways to handle request if the corresponding microservice is unavailable

Service Discovery: Monitor the new microservice launch and add it to network, so that other microservice could find it.

3.

Resilience patterns could define options to help services remain avaliable even when some failure in the underlying services. Options include retry, circuit breaker, fallback etc

Below code defines a fallback strategy. If REST call in getProduct method failed, it will switch to  getProductFallback methd.

```
    @HystrixCommand(
      commandKey = "getProduct",
      fallbackMethod = "getProductFallback",
      commandProperties = {
        @HystrixProperty(name = "execution.isolation.thread.timeoutInMilliseconds", value = "2000"),
        @HystrixProperty(name = "circuitBreaker.requestVolumeThreshold",    value = "10"),
        @HystrixProperty(name = "circuitBreaker.errorThresholdPercentage",  value = "50"),
        @HystrixProperty(name = "circuitBreaker.sleepWindowInMilliseconds", value = "5000")
      }
    )
    public Product getProduct(Long id) {
    }

    public Product getProductFallback(Long id) {
    }
```

4.

Load balancing algorithm is the algorithm used by load balancer to maximize the performance of system, include:

Round Robin: Cycles through a list of available service instance

Weighted Round Robin: Like round robin, but stronger node get more request 

Least connections: Choose service that current active connection is lowest

5.

API gateway is a special, dedicated service that stand between clients and a set of background microservice, it is responsible for routing the incoming calls for correct service to handle, transforming the request format to the format used by underlying services, gathering response and send back to user

6.

Service registry is a database that holds the network location of microservices instances, it is needed for microservices to connect with each other

Service discovery is the process that a service locates and connects to a instance of other service, usually via load balancer
