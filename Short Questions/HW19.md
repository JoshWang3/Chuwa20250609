3. Compare let vs var , explain variable hosting with your own code examples.
var is function-scoped, hoisted and initialized to undefined; 
let is block-scoped, hoisted but in a Temporal Dead Zone until declared.
```angular2html
console.log(a); // undefined
var a = 1;

console.log(b); // ReferenceError (TDZ)
let b = 2;

if (true) {
  var x = 10;
  let y = 20;
}
console.log(x); // 10
console.log(y); // ReferenceError
```

4. Explain closure with code example
A closure is when a function “remembers” variables from its outer scope even after that scope has finished executing.
```angular2html
function makeCounter() {
  let count = 0; // preserved in closure
  return function () {
    count++;
    return count;
  };
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3
```

5. Explain Callback Hell with code example
Callback Hell happens when you have many nested callbacks — usually in asynchronous code — making it hard to read, debug, and maintain.
```angular2html
getUser(1, function(user) {
  getPosts(user.id, function(posts) {
    getComments(posts[0].id, function(comments) {
      getLikes(comments[0].id, function(likes) {
        console.log("Done!", likes);
      });
    });
  });
});
```

6. Explain Promise, Async, Await with code examples.
A Promise is an object representing the eventual result (success or failure) of an asynchronous operation.
```angular2html
const myPromise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve("Done!");
  }, 1000);
});

myPromise
  .then(result => console.log(result))   // when resolved
  .catch(error => console.error(error)); // when rejected
```

async marks a function so it always returns a Promise.
await pauses inside an async function until the Promise settles (no .then() chaining needed).
```angular2html
function getData() {
  return new Promise(resolve => {
    setTimeout(() => resolve("📦 Data loaded"), 1000);
  });
}

async function main() {
  console.log("Loading...");
  const data = await getData(); // waits here
  console.log(data);            // 📦 Data loaded
}

main();
```

9. Explain how Javascript implement asynchronous non-blocking feature
JavaScript async & non-blocking: Event Loop, Macrotask, Microtask
Mental model
-Call Stack runs your JS synchronously.
-Async APIs (timers, fetch, DOM, I/O) hand work to Web/Node APIs.
-When they finish, callbacks are queued as tasks.
-The Event Loop repeats:
1)If stack empty → run all microtasks;
2)Then take one macrotask;
3)Render (browser); repeat.

Microtasks: Promise.then/catch/finally, queueMicrotask, (Node: process.nextTick).
Macrotasks: setTimeout, setInterval, setImmediate(Node), message, I/O, UI events.
