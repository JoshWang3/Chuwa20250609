3.

var have a function scope, All variable defined with var in a function will share a same reference. let have a block scope, only accessible in a block.

In variable hoisting, var definition will hoist to the beginning of the function, initialized with undefined.

```
console.log(x); // undefined 
var x = 1;
console.log(x); // 1
```

let definition will hoist to the beginning of the block, not initialized before declared.

```
console.log(y); // ReferenceError
let y = 1;
console.log(y); // 1
```

4.

Closure is about function persist the variable from its lexical scope even after function finished

```
function makeCounter() {
  let count = 0; 
  return function() {
    count++; 
    console.log(count);
  };
}

const counter = makeCounter(); 

counter(); // 1
counter(); // 2
counter(); // 3
```

Callback hell is about multiple async operations are nested inside each other for callback, make the code hard to read, debug and error prone.

```
getUser(1, function (err, user) {
    if (err) {
        console.error("Error getting user:", err);
    } else {
        getProfile(user.id, function (err, profile) {
            if (err) {
                console.error("Error getting profile:", err);
            } else {
                displayProfile(profile, function (err, result) {
                    if (err) {
                        console.error("Error displaying profile:", err);
                    } else {
                        console.log("Profile displayed successfully!");
                    }
                });
            }
        });
    }
});
```



6.

Promise is an object that represent result of async operation. 

```
const myPromise = new Promise((resolve, reject) => {
    let success = true;

    setTimeout(() => {
        if (success) {
            resolve("success");
        } else {
            reject("error");
        }
    }, 1000);
});

myPromise
    .then(result => {
        console.log(result); 
    })
    .catch(error => {
        console.error(error);
    });
```



async is keyword that put before a function to make function return promise automatically. await keyword could be used inside async function to pause execution until promise is resolved or rejected.



```
function fetchData() {
    return new Promise(resolve => {
        setTimeout(() => resolve("Data loaded"), 1000);
    });
}

async function load() {
    console.log("Start loading...");
    const data = await fetchData();
    console.log(data);
}

load();
```

9.

JavaScript runs one thing at a time on call stack. Event loop is a scheduler that 

a. runs things on call stack

b. If end synchronous code, drains microtasks it triggers

c. then pick next macrotask 

microtasks, like promise.then, run immediately after the current synchronous code finishes and before the next macrotask and browser render

macrotasks, like setTimeout, setInterval, are task that scheduled for future



```
console.log('A: sync start');

setTimeout(() => console.log('E: timeout macrotask'), 0);

Promise.resolve()
  .then(() => console.log('B: microtask then #1'))
  .then(() => console.log('C: microtask then #2'));

queueMicrotask(() => console.log('D: microtask via queueMicrotask'));

console.log('F: sync end');
```

Tasks running order is A F B C D E
