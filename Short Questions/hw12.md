## Question 2
TLS (Transport Layer Security) - cryptographic protocol that secures communication over networks, like when you visit an HTTPS website. It encrypts data in transit to prevent eavesdropping and tampering.

PKI (Public Key Infrastructure) - framework of policies, procedures, and technology that manages digital certificates and public-private key pairs. It's the trust system that makes secure communications possible at scale.

Certificate - digital document that binds a public key to an identity, issued by a trusted Certificate Authority (CA).

Public key - one half of a cryptographic key pair that can be freely shared. It's used to encrypt data that only the corresponding private key can decrypt, or to verify signatures created with the private key.

Private key - the secret half of the key pair that must be kept secure. It's used to decrypt data encrypted with the public key or to create digital signatures.

Signature - cryptographic proof that a message came from the holder of a private key and hasn't been tampered with.

## Question 12
Bearer tokens contain all the information needed to grant access to protected resources. It is stateless, usually sent in HTTP header. 

JWT is a specific type of bearer token that follows an open standard for securely transmitting information as a JSON object.
- Format: Header.Payload.Signature
- upon authentication, the server creates a JWT with user information in the payload, return to client. Client includes JWT in requests.
