 2. Explain TLS, PKI, certificate, public key, private key, and signature.
    1. TSL(Transport Layer Security) TLS is a protocol that ensures secure communication over a network by encrypting data. It protexts against eavesdropping, tampering and message forgery.
    2. PKI(Public Key Infrastructure): PKI is a system that manages digital certificates and public-private key pairs to enable secure communication. It includes:certificate authorities(CA), registration authorities(RA), digital certificates, crytographic keys
    3. Certificate: A certificate is a digital document issured by a CA that binds a public key to an entity (like a domain or organization). It verifies that authenticity of the entity.
    4. Public key: the public key is part of a cryptographic key pair used in asymmetric encryption. It is shared publicly and used for encryption or verifying signatures
    5. Private key: The private key is the secret part of the key pair, used for decryption or creating digital signatures. It must be kept secure.
    6. Signature: A digitak signature is a cryptographic method to ensure the integrity and authenticity of a message fo document. It is created using the private key and verified using the public key.

 6. Explain HTTP Session?
    An HTTP session is a server-side mechanism to store user-specific data cross multiple requests. It uses a unique session ID to track interactions.
 7. Explain Cookie? 
    A cookie is a small piece of data stored on the client-side and sent to the server with each request. It is sued for session tracking, preferences and authentication.

    | Size limit | No size limit               | Limited to 4kb                    |
    | Use Case   | Storing sensitive user date | Storing non-sensitive preferences |
