```
@OneToMany: one entity is related to many other entities.
@ManyToOne: many entities are associated with one.
@ManyToMany: each side can have many references to the other, a middle table will be created
@Scope: defines the scope of a Spring bean
@JoinColumn: reference the column to the column of another table

Bean register: 
@Component: on top of the class
@Bean: on top of the method which returns a new instance of that type

@PreAuthorize: define access control rules directly on methods, specifying which users or roles are permitted to execute that method. 
```
