<p> 1. Explain monolithic architecture, service oriented architecture and Microservice architecture. </p>

<p> monolithic architecture: tightly integrated and deployed as a single unit </p>

<p> service oriented architecture: use software components called services to create business applications. 
Each service provides a business capability, and services can also communicate with each other across platforms 
and languages. </p>

<p> Microservice architecture: splits one application into small and independent service based applications. 
Independently deployed and loosely coupled. </p>

<p> 2. Document the microservice architecture and core components </p>

<p> API gateway: acts as a proxy, routing requests to the appropriate backend services </p>

<p> Load Balancer: a device or system that distributes network traffic across multiple servers or resources to optimize 
resource utilization, maximize throughput, minimize response time, and avoid overload</p>

<p> Circuit Breaker: preventing an application from repeatedly trying to execute an operation that is likely to fail, 
which can lead to cascading failures across the system.</p>

<p> Service Discovery or Service Registry: document service information including their names, urls, etc. </p>

<p> 3. Explain Resilience patterns? Explain circuit breaker with Spring Cloud Hystrix code example. </p>

<p> Resilience patterns help microservices systems remain functional during partial failures, slow responses, 
or unavailability of dependent services. These patterns prevent cascading failures and improve system stability and user experience.</p>

```
@Service
public class ProductService {

    @HystrixCommand(fallbackMethod = "getDefaultProducts")
    public List<String> getProducts() {
        if (new Random().nextBoolean()) {
            throw new RuntimeException("Service unavailable");
        }
        return Arrays.asList("Laptop", "Phone", "Tablet");
    }

    public List<String> getDefaultProducts() {
        return Arrays.asList("Default Product");
    }
}
```
