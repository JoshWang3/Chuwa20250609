Encapsulation involves combining data (variables) with the methods (functions) that operate on them within a single class.

Java implements Encapsulation by declaring class variables as private to prevent direct external access and providing public getter and setter methods as controlled ways to access and modify these variables. 

Encapsulation:
1. Hides the internal workings of an object, exposing only necessary information through public methods.
2. Accessing variables through methods allows for data control and integrity, preventing unauthorized changes.
3. Simplifying code and ensure reusability.
